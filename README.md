# movieedit2 - 顔ブラーエディター

自動顔検出 → ブラウザエディターで修正・ブラー調整 → mp4 書き出し、まで完結するツール。
プロジェクトはセーブファイル（`projects/*.mvproj.json`）に自動保存され、閉じても続きから作業できる。

## 起動

```bash
cd ~/projects/movieedit2
python run_editor.py            # → http://localhost:8765
```

### Claude 自動クリックを有効にする

プロジェクト直下の `.env` にAPIキーを記入してサーバーを再起動する:

```
ANTHROPIC_API_KEY=sk-ant-xxxxx
```

## 使い方

1. **スタート画面**
   - 「プロジェクトを開く」: 既存のセーブファイルから再開（前回の作業フレーム位置も復元）
   - 「新規プロジェクト」: 動画フォルダ（デフォルト `~/projects/movieedit/input`）から選択、またはパス直接指定
2. **自動検出**（2エンジン。どちらも対象領域を「顔全体 / 口元のみ」から選択可能）:
   - 「🔍 高速検出」: InsightFace/SCRFD + IoU トラッキング。速いが横顔・後ろ姿で途切れる
   - 「🎯 高精度追跡」: **SAM 2 時間伝播 + ArcFace アンカー + Claude 自動クリック**。
     口元のみモードでは、追跡した頭部領域を毎フレーム切り出してランドマークを**実測**し
     （小さい顔は拡大して検出）、口が見えないフレームだけ相対位置の補間で埋める
     （カメラの寄り/引きにも追従。口が見えない向きでも口があるはずの位置をブラーし続ける）。
     実行中は「ライブ表示」で検出位置をオレンジ枠でリアルタイム確認できる。
   - Claude API の使用時はツールバーに「🤖 API呼び出し中…」と累計使用量
     （回数・概算コスト。詳細はツールチップ）が表示される（`api_usage.json` に永続化）
     サイドバーの設定で対象を選ぶ:
     - 「映っている全員」: 検出した全人物を SAM 2 で追跡
     - 「特定人物（リファレンス照合）」: 「🖱 動画から対象人物を選択」でフレーム上の顔を
       クリックして登録（顔画像パスの直接指定も可。サムネイルクリックで削除）→
       ArcFace で本人のフレームを探し（アンカー）、SAM 2 がマスクを前後双方向に伝播。
       伝播中も定期的に本人照合し、すれ違いによるすり替わりを自動棄却。
       ArcFace で白黒つかない曖昧ケース（類似度0.18〜0.40）は Claude が
       髪型・服装から二次判定（クールダウン+回数上限つき）。
       残った穴は Claude vision が頭部座標を回答して再シード
       （`ANTHROPIC_API_KEY` 設定時のみ。未設定なら自動スキップ）
3. **修正**:
   - 楕円をドラッグで移動、白ハンドルでサイズ変更、◎ハンドル（上）で回転
     （現在フレームに手動キーフレームを打つ）
   - 「▶ ここから再追跡 (SAM 2)」: 手動修正した楕円をシードに、以降を SAM 2 で
     検出し直す（次の手動キーフレームまで・最大240フレーム）。修正を引き継ぐ本命の方法
   - 「⇥ 以降のフレームへ伝播」: このフレームの修正量（移動・拡縮・回転）を、
     次の手動キーフレームの手前まで後続の自動キーフレームすべてに適用（幾何オフセットのみ・高速）
   - 「＋追加」→ キャンバスをクリックで人物を手動追加
   - 「表示/非表示 切替」でブラーの ON/OFF 区間を制御
   - タイムライン下の帯: 人物ごとのキーフレーム分布（白線 = 手動キーフレーム）
   - 表示操作: マウスホイールで拡大縮小（カーソル位置基準）、
     ホイールドラッグで移動、`0` キーでリセット
   - フレーム番号入力欄（タイムライン左）に番号を入れて Enter で直接ジャンプ
   - `A` = 1フレーム戻る / `S` = 現在の楕円をシードに **SAM 2 で1フレームだけ伝播して進む**
     （難しい場面をコマ送りで確認しながら追跡できる。1回 2〜3秒）
   - 検出できない区間は、マスクが最寄りの**画面端のすぐ外**に待機する（グレー破線）。
     ブラーは掛からず、ズームアウトすれば掴んで戻せる
   - API使用量はプロジェクト別に集計され、トップページに全体累計を表示
4. **ブラー調整**: 人物を選択 → 種類（ガウシアン/モザイク）・濃さ・フェザーをスライダーで調整。
   「ブラープレビュー」にチェックで実際の合成結果を確認
   - **濃さキーフレーム**: 「◆ 濃さKF」で現在フレームに濃さのキーを打つと、
     以降キーフレーム間で線形補間される（カメラの寄り/引きに合わせた濃度変化）。
     KFモード中はスライダー操作が現在フレームへの自動キーになる（AEのストップウォッチON相当）。
     濃さ0でそのフレームはブラーなし。タイムラインに黄色マーカーで表示
5. **漏れQC**: 「✅ 漏れQC」でブラー合成結果をサンプリング検品 → 漏れを自動修正
   - Stage A（ローカル・無料）: ブラー後の映像に本人の顔が検出できてしまうフレームを特定
     → 正確な bbox をシードに SAM 2 で自動修正
   - Stage B（Claude API）: 対象のキーフレームが無い「未カバー区間」+ 抜き取り分だけを
     Claude が検品（横顔などローカル検出が拾えない漏れ用。呼び出し数は穴の数に比例）
   - 修正 → 再検品を最大2周。直らなかった漏れはタイムライン最上段に **赤▼マーク** で表示
6. **書き出し**: 「🎞 mp4書き出し」→ `output/` に保存（NVENC 使用、音声パススルー）

キーボード: `Space` 再生/停止, `←/→` 1フレーム移動（`Shift` で10フレーム）

## セーブファイル

`projects/{id}.mvproj.json` に以下をすべて保存（編集の1.2秒後に自動保存）:

- 動画情報（パス・fps・フレーム数・解像度）
- 人物リスト（ラベル・色・有効/無効・ブラー設定・領域 face/mouth）
- キーフレーム（人物ごと: 楕円 cx/cy/rx/ry/angle（回転）・表示・auto/manual 区別）
- 高精度追跡の設定（対象モード・リファレンス画像パス）
- UI 状態（最後に見ていたフレーム位置）

## 構成

```
app/
├── main.py      FastAPI ルーティング
├── project.py   セーブファイル管理（原子的書き込み）
├── video.py     フレーム供給（VideoCapture キャッシュ）
├── render.py    キーフレーム補間（回転対応）+ ブラー合成（プレビューと書き出しで共通）
├── detect.py    高速検出ジョブ（InsightFace、顔/口元 + 傾き）
├── tracker.py   高精度追跡ジョブ（ショット検出 → ArcFace アンカー → SAM 2 伝播
│                 → 自己検証 → Claude 自動クリック）
├── autoclick.py Claude vision による頭部座標の回答（再シード用）
├── export.py    mp4 書き出しジョブ（ffmpeg パイプ）
└── static/      エディター UI（index.html / app.js / style.css）
models/          SAM 2.1 チェックポイント（sam2.1_hiera_base_plus.pt）
projects/        セーブファイル（.mvproj.json）
output/          書き出した mp4
```
